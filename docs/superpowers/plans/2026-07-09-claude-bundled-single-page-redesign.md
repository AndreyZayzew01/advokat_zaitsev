# Claude Bundled Single-Page Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current routed website with the exact bundled one-page Claude export, personalize it with existing site data, and provide a validated mock submission notification.

**Architecture:** Keep the Claude export, manifest, template, unpacker, custom tags, and `DCLogic` runtime intact. Store the untouched export as a vendor source and use one deterministic Node script to inject the existing lawyer data, article summaries, portrait asset, and form-notification behavior into the committed root `index.html`. Remove the old SPA implementation after regression tests cover the bundle contract.

**Tech Stack:** HTML bundle generated by Claude, JavaScript/`DCLogic`, Node.js build script, Vite 5, Vitest 4, jsdom, GitHub Pages.

## Global Constraints

- Preserve the supplied Claude bundler, manifest, template, custom tags, runtime, colors, typography, spacing, layout, and responsive rules.
- Use `C:\Users\55\Desktop\Адвокат Хакасия - сайт.html` as the authoritative design source.
- The site is one page; header links use anchors and smooth scrolling.
- Use existing data for Зайцев Валерий Олегович, more than 15 years of practice, services, address, email, and article summaries.
- Keep `+7 (777) 777-77-77` and `https://t.me/` as temporary contact placeholders.
- Keep mock education, registry, certificate, and career data where the old site has no real values.
- Article cards do not navigate to separate article pages.
- Do not send form data over the network.
- After valid form input, show the exact user-facing text `Письмо отправлено`.
- Physically delete the old pages, router, old CSS, and unused old interaction modules.
- Keep the Vite/GitHub Pages build functional.

```ts
export interface ManifestEntry {
  mime: string;
  data: string;
  compressed?: boolean;
}

export interface BundleFixture {
  html: string;
  template: string;
  manifest: Record<string, ManifestEntry>;
}

function scriptBody(html: string, type: string): string {
  const pattern = new RegExp(
    `<script type="${type}">\\s*([\\s\\S]*?)\\s*<\\/script>`,
  );
  const match = html.match(pattern);

  if (!match) {
    throw new Error(`Missing ${type} script`);
  }

  return match[1];
}

export function readBundle(): BundleFixture {
  const html = readFileSync(
    new URL('../index.html', import.meta.url),
    'utf8',
  );

  return {
    html,
    manifest: JSON.parse(scriptBody(html, '__bundler/manifest')),
    template: JSON.parse(scriptBody(html, '__bundler/template')),
  };
}
```

```js
function scriptMatch(type) {
  const pattern = new RegExp(
    `<script type="${type}">\\s*([\\s\\S]*?)\\s*<\\/script>`,
  );
  const match = html.match(pattern);
  if (!match) throw new Error(`Missing ${type}`);
  return { pattern, body: match[1] };
}

function replaceOnce(value, before, after, label) {
  const parts = value.split(before);
  if (parts.length !== 2) {
    throw new Error(`${label}: expected one match, found ${parts.length - 1}`);
  }
  return `${parts[0]}${after}${parts[1]}`;
}

function replacePatternOnce(value, pattern, after, label) {
  const matches = value.match(new RegExp(pattern.source, pattern.flags + 'g'));
  if (!matches || matches.length !== 1) {
    throw new Error(`${label}: expected one match, found ${matches?.length ?? 0}`);
  }
  return value.replace(pattern, after);
}
```
